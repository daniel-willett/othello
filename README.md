The board game Othello

Setup:
- 8x8 grid with middle 4 squares taken by oppoesing tiles along the diagonals
Rules:
- Take it in turns to place on the board
- Place 1 tile on the board - It must 'surround' enemy tiles
- Surrounded tiles are flipped to your side


This will initially be started in Python in TKinter. From there I may branch out into other languages
